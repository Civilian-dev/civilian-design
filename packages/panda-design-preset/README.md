# @civilian-dev/panda-design-preset

Panda CSS preset generated from `@civilian-dev/design-tokens`. Variable names match the tokens' CSS (`--colors-bg-canvas`, `--spacing-4`, …), so both can coexist.

## Usage

Use Panda's base preset only, **without** Panda's default preset, so scale steps that the design system removed don't come back:

```ts
// panda.config.ts
import { defineConfig } from "@pandacss/dev";

export default defineConfig({
  presets: ["@pandacss/preset-base", "@civilian-dev/panda-design-preset"],
  include: ["./src/**/*.{ts,tsx}"],
  outdir: "styled-system",
});
```

- Colours: semantic roles are `semanticTokens.colors` with `{ base, _dark }`; primitives are plain tokens. Use the roles (`bg.canvas`, `fg.default`).
- Dark mode: `_dark` matches `[data-theme="dark"]`, and `@media (prefers-color-scheme: dark)` on `:root:not([data-theme="light"])`.
- Text styles: `textStyle: "heading.display"`, `"body.medium"`, `"label.small"`, `"code.small"`.

`src/preset.ts` is generated by `pnpm build`; never edit it by hand.
